## **📌 Phase 1: Getting Started (Beginner Level)**  

<!-- ### 🎯 **Duration:** 2 Weeks   -->
### 🏆 **Goal:** Learn DOM selection, event handling, and basic manipulations.  

### 👨‍💻 **Topics to Cover:**  
- ✅ Selecting elements: `getElementById`, `querySelector`, `querySelectorAll`  
- ✅ Modifying text: `innerText`, `textContent`, `innerHTML`  
- ✅ Changing styles dynamically: `style` property, `classList`  
- ✅ Handling events: `click`, `input`, `change`, `keydown`, `keyup`, `mouseenter`, `mouseleave`  
- ✅ Working with attributes: `setAttribute`, `getAttribute`, `removeAttribute`  

### 💻 **Hands-on Mini Projects:**  
1. 🎨 **Background Color Changer** – Change the background color on button click.  
2. 🔢 **Click Counter** – Increase and decrease a number using buttons.  
3. ✍️ **Character Counter** – Display live character count as a user types.  
4. 🔐 **Show/Hide Password** – Toggle password visibility.  
5. 🧮 **Simple Calculator** – Basic arithmetic operations with buttons.
