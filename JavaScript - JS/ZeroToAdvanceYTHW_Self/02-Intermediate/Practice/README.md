# 🧠 JavaScript Practice Repository

This repository contains structured JavaScript practice files organized by topics like arrays, loops, sets, symbols, and higher-order functions. Each topic demonstrates core JS concepts with simple, beginner-friendly code examples.

---

## 📁 Folder Structure & Topics

### 📂 `arrayMethods/`

**Practice using spread operator and object arrays.**

- [`animeArray.js`](./arrayMethods/animeArray.js) → Creating and extending arrays using the spread operator with anime objects.

---

### 📂 `spreadRest/`

**Understanding rest parameters and function arguments.**

- [`addItem.js`](./spreadRest/addItem.js) → Uses rest parameters to pass multiple values and print them in table format.

---

### 📂 `higherOrderFunctions/`

**Core functions like filter, map, find, some, every, and reduce.**

- [`01_filterAnime.js`](./higherOrderFunctions/01_filterAnime.js) → `.filter()`: Filter anime based on rating and genre.
- [`02_mapAnime.js`](./higherOrderFunctions/02_mapAnime.js) → Use `.map()` to transform anime data into formatted strings.
- [`03_findCheck.js`](./higherOrderFunctions/03_findCheck.js) → Use `.find()` to check anime data.
- [`04_everyCheck.js`](./higherOrderFunctions/04_everyCheck.js) → Use `.every()` to check anime data.
- [`05_someCheck.js`](./higherOrderFunctions/05_someCheck.js) → Use `.some()` to check anime data.
- [`06_reduceAverage.js`](./higherOrderFunctions/06_reduceAverage.js) → Calculate total and average rating using `.reduce()`.

---

### 📂 `setsSymbols/`

**Learning how to use `Set` and `Symbol` in JavaScript.**

- [`01_setPractice.js`](./setsSymbols/01_setPractice.js) → Add, delete, check, iterate, and clear data using `Set`.
- [`02_symbolPractice.js`](./setsSymbols/02_symbolPractice.js) → Use `Symbol` to add hidden properties in an object and access them securely.

---

### 📂 `loops/`

**Mastering the `for...of` loop for object arrays.**

- [`forOfPractice.js`](./loops/forOfPractice.js) → Traverse through anime list and log uppercase names with genres.

---

## 💡 Tip:

All examples are logged using `console.log()` and `console.table()` for better terminal readability.
