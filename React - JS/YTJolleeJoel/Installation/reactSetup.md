# How to Install and Setup React with Vite

React can be set up in different ways, but one of the fastest and most modern methods is using **Vite**. Follow the steps below to get your React project up and running.

---

## 1. Prerequisites

Before starting, make sure you have **Node.js** installed on your system.

* Check Node.js version:

  ```bash
  node --version
  ```

  React projects typically work best with Node.js **v16 or higher**.

---

## 2. Create a New React Project with Vite

1. Open your terminal and run:

   ```bash
   npm create vite@latest
   ```

2. When prompted, enter a **project name** (example: `react_app`).

3. Choose a **framework**:

   * Select: `React`

4. Choose a **variant**:

   * Select: `JavaScript` (you can also choose TypeScript if you prefer).

---

## 3. Navigate and Install Dependencies

After setup, follow the instructions given in the terminal:

1. Go to your project folder:

   ```bash
   cd react_app
   ```

2. Install required dependencies:

   ```bash
   npm install
   ```

---

## 4. Run the Development Server

Start your React app with:

```bash
npm run dev
```

This will launch the development server, and you’ll see a local URL (e.g., `http://localhost:5173`). Open it in your browser to view your React application.

---

✅ You now have a fully working React project created with Vite.
